# 소방 계통도 훈련판

소방시설 계통도를 익히는 수업용 앱입니다. 옥내소화전설비, 습식·준비작동식 스프링클러설비, 자동화재탐지설비를 다룹니다.

- **탐색:** 부품의 용도, 실물 사진, 앞뒤 연결을 보고 화재 시나리오를 단계별로 재생합니다.
- **빈칸 퍼즐:** 랜덤으로 비운 칸에 부품을 넣습니다.
- **연결 그리기:** 섞인 부품을 이어 배관과 신호선을 완성합니다.
- **동작 순서:** 동작 카드를 순서대로 맞춥니다.

문제 번호가 같으면 모두 같은 문제가 나옵니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev       # 개발 서버
npm test          # 단위 테스트
npm run build     # dist 폴더에 배포본 생성
npm run preview   # 배포본 확인
```

## 배포

### 웹앱(PWA)

현재 주소: https://skh9991.github.io/fire-system/

`dist` 폴더를 HTTPS 정적 호스팅에 올립니다(GitHub Pages, Netlify, 학교 웹서버 등). 접속 후 브라우저의 "홈 화면에 추가" 또는 "앱 설치"를 누르면 설치되고, 한 번 연 뒤에는 인터넷 없이 실행됩니다.

### Android 앱

Android Studio가 있는 PC에서 실행합니다.

```bash
npm run android:add     # 처음 한 번
npm run android:sync
npm run android:open    # Android Studio에서 빌드
```

스토어 등록 전에 `capacitor.config.ts`의 `appId`를 고유한 주소로 바꾸세요. iOS는 Mac과 Xcode, `@capacitor/ios` 패키지가 필요합니다.

## 실물 사진 넣기

1. **이 기기에서만 쓰기:** 앱의 교수 모드를 켜고 부품을 누른 뒤 사진을 넣습니다. 사진은 그 기기에만 저장됩니다.
2. **모든 학생에게 배포하기:** 사진을 `public/photos`에 넣고 `src/data/photos.ts`에 부품 이름과 파일명을 등록한 뒤 다시 빌드합니다. 사용 권리가 있는 사진만 넣으세요.

교수 모드는 비밀번호가 없는 화면 전환 기능입니다.

## 내용 검수

수치와 설치 위치는 현행 화재안전기술기준(NFTC 102, 103, 203)과 대조한 뒤 수업에 사용하세요. 옥내소화전 도면의 "25m 이상" 표기는 참고 도면을 옮긴 것으로, 뜻을 확인해야 합니다.
